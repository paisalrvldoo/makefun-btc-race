Patient 24-bar momentum bot for make.fun's BTC paper race (cbBTC/USDC).
One entry + 6% hard stop; never re-enters.
Paper money only.

## Run it

```sh
node /bot/main.ts
```

Locally, the harness pipes hello/batch NDJSON; for a local grade use the kit CLI `grade-local`.
